## 🚀 Қалай ашуға болады?

Сайт ешқандай қосымша орнатуды (Node.js, npm, Python) талап етпейді:
- Осы жоба қалтасындағы `index.html` файлын екі рет басып кез келген браузерде (Chrome, Edge, Safari, Firefox) ашуға болады.
- Сайт толықтай мобильді құрылғыларға (смартфондар мен планшеттерге) бейімделген.
- Интернетке орналастыру үшін осы қалтадағы файлдарды GitHub Pages, Netlify немесе кез келген хостингке жүктеу жеткілікті.

## 📁 Файлдар құрылымы:
- `index.html` — Дүкеннің толық HTML5 қаңқасы, модальдар, себет және ЖИ виджеті
- `style.css` — Заманауи алтын-қара премиум дизайн жүйесі (CSS3, responsive)
- `products.js` — Тауарлар дерекқоры және бастапқы пікірлер
- `app.js` — Тіл ауыстыру, себет, Kaspi QR, ЖИ оператор мен WhatsApp логикасы
